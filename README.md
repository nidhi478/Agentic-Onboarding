# PayGlocal Conversational Onboarding App

A runnable React + Vite + Tailwind demo implementing a 3-column conversational onboarding flow with:
- Progress tracker
- Echo chat flow
- Dynamic canvas
- Collapsible summary panel

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in terminal.
